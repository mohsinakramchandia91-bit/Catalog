Onyx AI Labs is a small independent software studio run by Muhammad Mohsin in Pakistan. It builds practical AI and automation tools on a simple principle: you pay once, you own the tool forever, and it keeps working without a monthly fee.

Most software now rents itself to you. These tools don't. Each product below is a one-time purchase with a 14-day money-back guarantee, and wherever a product depends on an outside service (an AI API, a messaging platform), it runs on your own account and keys — so nothing here can be switched off for you, and nothing costs us a server bill that has to be passed on to you.
