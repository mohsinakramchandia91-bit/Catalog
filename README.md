# Catalog — Onyx AI Product Catalog

The official product catalog website for **Onyx AI** by Muhammad Mohsin. A fast, single-page static site that presents his digital products — AgentKit, ContractKit, WhatsAppKit, and more — with cover art, pricing, coupon codes, Gumroad buy links, demo videos, and WhatsApp contact buttons.

Live site: https://onyxailabs.github.io/Catalog/

## Features

- Product cards with cover art, descriptions, and pricing
- "Buy" buttons linking to Gumroad checkout pages
- "WhatsApp" buttons for direct sales chat
- Coupon code badges
- 100% static — plain HTML + CSS, no build step, no dependencies
- Deployed with GitHub Pages

## How to use

Open the live site: https://onyxailabs.github.io/Catalog/

To run locally, open `index.html` (or `catalog.html`) in any browser — no server needed.

To add a product: duplicate a `.card` block in `index.html`, drop its cover image into `assets/`, update the title, description, price, coupon, and buy/demo/WhatsApp links, then commit. GitHub Pages redeploys automatically.

## Files

- `index.html` — main catalog page
- `catalog.html` — alternate catalog layout
- `assets/` — product cover images and site assets
